# Canada and UK implementation plan

**Goal:** Canadian and UK trainers can list and book in their local currencies;
owners can browse publicly and search local postal areas.

**Architecture:** Extend existing listing/search flows with supported countries
and approximate postal areas. Store currency on services and immutable booking
snapshots. Keep the existing scheduling rules with current IANA timezone data.

**Spec:** `docs/superpowers/specs/2026-09-18-canada-uk-design.md`.

## Constraints

- Existing US listings and bookings remain US/USD.
- Local Supabase only; email log mode; no hosted changes or deployment.
- Node 22 and pnpm 10.33.2 remain pinned. No new service account required.
- Database changes use new migrations and preserve RLS/grants.
- Working copy is isolated on `codex/canada-uk-support` inside the original
  project's ignored `docs/scratch/canada-uk-implementation` directory, because
  original Git metadata is read-only and edits outside the project were denied.
